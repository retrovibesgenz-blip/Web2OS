HOW IT WORKS

Three steps, every time.

There's no path from "call the API" to "action performed" that skips the person at the keyboard.

01

Get a key

Keys are issued from the user's own Web2OS Dashboard, or requested live — either way the user sees who's asking and approves it. There's no self-serve endpoint that hands out access quietly.

02

Call the API

Your site sends a normal POST request to the Web2OS agent running on 127.0.0.1 — your API key, the action, and its payload.

03

The user decides

A native popup shows exactly what you're asking to do. Allow runs it. Deny — or 65 seconds of silence — rejects it. Every decision is written to their activity log.

Same endpoint, three languages. The agent listens on http://127.0.0.1:8765 on the user's own machine.

import requests

resp = requests.post(
    "http://127.0.0.1:8765/api/action",
    json={
        "api_key": "w2os_your_issued_key",
        "action_type": "create_file",
        "payload": {
            "path": "~/Desktop/export.csv",
            "content": "id,total\n1,42.00\n",
        },
    },
)

data = resp.json()
if data["success"]:
    print("Saved:", data["message"])
else:
    # user denied, or Web2OS isn't running / is paused
    print("Not saved:", data["message"])

async function saveExport(csvText) {
  const resp = await fetch("http://127.0.0.1:8765/api/action", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      api_key: "w2os_your_issued_key",
      action_type: "create_file",
      payload: { path: "~/Desktop/export.csv", content: csvText },
    }),
  });

  const data = await resp.json();
  if (data.success) {
    console.log("Saved:", data.message);
  } else {
    // user denied, or Web2OS isn't running / is paused
    console.warn("Not saved:", data.message);
  }
}

SECURITY MODEL

What we won't build.

These aren't roadmap items — they're the boundaries the agent enforces in code.

● NO SILENT REGISTRATION

Every new integration is approved, not assumed

A site can't add itself as trusted in the background. Registering a key shows the same on-screen popup as any other action, naming the requester.

● NO HIDDEN PROCESS

Web2OS is always visible while it runs

A tray icon is present at all times with a live status and a one-click Dashboard. If it's not in the tray, it isn't running — full stop.

● FULL AUDIT LOG

Every request, allowed or denied

The Dashboard's Activity tab shows who asked for what and when, going back through the most recent requests — not just the ones that succeeded.

● ONE-CLICK REVOKE + PAUSE

The user is always back in control

Any integration can be revoked instantly from the Dashboard, and a single Pause switch stops all requests from every integration at once.
